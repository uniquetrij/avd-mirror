# Screenshots

Assets the marketplace listing and the README use. Two are referenced by name
from `readme.md` (in the commented block near the top); drop them in here and
uncomment that block.

| File | What to capture |
| --- | --- |
| `mirror-panel.png` | VS Code with the **AVD Mirror** panel open showing a running emulator, the **AVDs** tree beside it, and the toolbar visible. This is the listing's first impression. |
| `avds-menu.png` | The same window with an AVD row's context menu open, showing the four surface switches and **Hide Emulator Window**. This is what shows the per-AVD control. |
| `hidden-emulator.png` | Optional: the mirror still streaming at full rate while the emulator window is absent from the desktop and the taskbar. This is the feature nothing else has. |

Guidelines:

- Capture at a normal window size, not maximised on a 4K display: the gallery
  renders roughly 900 px wide, and a downscaled 4K shot is unreadable.
- Keep the emulator screen free of anything private. A launcher home screen or a
  stock sample app is ideal, because it is recognisably Android without showing
  your own data.
- `png` or `gif` both work in the README; a short `gif` of a two-finger pinch is
  the most convincing thing to put in the listing.
